Trabajo con datos para que alguien pueda **decidir algo**, no para llenar un dashboard.

Antes de esto pasé dos años editando video para creadores de YouTube. Ahí aprendí a mirar
retención de audiencia y CTR todos los días, y a aceptar una regla simple: si un corte no
mejora un número, no va.

Hoy aplico lo mismo al análisis: pregunta de negocio primero, indicador después, gráfico al final.

### Proyecto destacado

**Riesgo de dependencia de las importaciones del Ecuador**
`650.426 declaraciones` · `SQL / BigQuery` · `Looker Studio`

> 2 de 97 categorías arancelarias concentran el **29% del valor importado** (US$ 4.391 M).
> Combustibles depende 73% de EE.UU.; máquinas eléctricas, 48% de China. El análisis también
> concluye dónde **no** vale la pena intervenir.
